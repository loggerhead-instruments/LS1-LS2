LS1/LS2 Set Clock

Sets the logger clock to this computer's time in UTC over USB.

  1. Plug the logger into USB and turn it on. Wait for the menu screen.
  2. Click Connect and pick the logger's port (usually a USB Serial / COM port).
  3. Click Set logger to UTC now.
